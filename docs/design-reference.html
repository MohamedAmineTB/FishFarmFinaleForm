From sensor to action

One reading, three hands,
six seconds.

1
every 6 s · 3 probes per basin

The sensor reads

Probes in each basin measure temperature, pH and dissolved oxygen and send every reading to the data pipeline.

2
clean · compare · store

The pipeline checks

Each reading is cleaned, compared with the safe range for the species in that basin, and stored for the charts and the oxygen prediction model.

3
worker · technician · owner

The right person acts

Water problems go to the worker on shift. A sensor that stops changing goes to the technician. The owner sees the summary and the money.
